# **App Name**: Rural Planner

## Core Features:

- Project Catalog Display: Showcase a comprehensive collection of +100 productive farm projects with detailed descriptions, organized by size, vocation, and climatic region.
- Interactive Sample Carousel: Provide a navigable image carousel displaying examples of project plan layouts and content.
- Dynamic Pricing and Countdown: Present 'Basic' and 'Pro' pricing plans with a prominent real-time offer countdown timer for urgency.
- Testimonial Showcase: Display authentic customer testimonials, including flags for country of origin, to build trust.
- Bonus Content Highlight: Feature strategic bonus materials (e.g., construction plans, ROI calculator) that complement the core project pack.
- Interactive FAQ Section: Implement a collapsible FAQ section to address common user questions about the product, payment, and access.
- AI-Powered Project Assistant: A tool that recommends suitable farm projects based on user-provided inputs such as land size, location, climate, and desired agricultural output.

## Style Guidelines:

- Primary color: A rich, earthy gold (#C9A961), symbolizing abundance and harvest, designed to contrast with the dark background.
- Background color: A deep, sophisticated brown (#211D15), derived from the primary's hue, to represent fertile soil and establish a luxurious dark theme.
- Accent color: A warm, rich reddish-brown (#9F381E), analogous to the primary, to draw attention and convey passion or urgency for calls-to-action and important information.
- Headline font: 'Playfair Display' (serif), chosen for its elegant and impactful presence, suitable for main titles and section headings. Note: currently only Google Fonts are supported.
- Body font: 'Inter' (sans-serif), providing a modern, neutral, and highly readable typeface for all body text. Note: currently only Google Fonts are supported.
- Minimalistic and relevant icons; leverage flag emojis for geographical representation in testimonials to enhance connection.
- Clean, modular, and responsive grid-based sections to present content in an organized and digestible manner across devices, emphasizing clear visual hierarchy.
- Subtle and purposeful transitions for interactive elements like buttons, cards, and accordion items (FAQs), enhancing user feedback without being distracting.
